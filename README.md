# Docker Apache Webserver

A simple Apache Web Server project deployed using Docker on an AWS EC2 instance.

## 🚀 Project Overview

This project demonstrates how to:

- Create a Docker image using a Dockerfile
- Install and configure Apache2 inside an Ubuntu-based container
- Copy website files into the Apache web root
- Expose port 80 from the Docker container
- Run an Apache web server using Docker
- Deploy the application on an AWS EC2 instance

## 🛠️ Technologies Used

- Apache2
